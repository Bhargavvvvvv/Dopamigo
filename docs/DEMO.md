# Three-minute demo

## Before presenting

Launch `npm run dev` or the built app. Set the local Google key and restart. Use **Preview Google voice** once to check model access and audio output. Keep Gentle selected unless you explicitly choose Playful. Install/pair the Chrome extension, or use the labelled manual trigger. End any current session before loading the sample.

## Rehearsal

1. **0:00 — Start small.** In Plan, enter “Literature review on urban green spaces” and paste: “Compare three studies on urban green spaces and student wellbeing. Write a 1500-word literature review with a methods comparison and one research gap.” Create a plan. Point out the next action and its completion condition. Mock mode is labelled; turn sample plans off to show a live Gemini result.
2. **0:35 — Make it workable.** Use **Make it smaller**, edit a step, then **Open workspace**. Start the session. Write a short note and set **My exact next action** to a specific sentence. Save a resource link.
3. **1:10 — Leave and return.** Pause, close/reopen, and show Return. Read the actual saved note and exact next action. **Continue working** resumes and opens the first saved resource. No unsaved thoughts or arbitrary app content are inferred.
4. **1:45 — Browser detour.** Enable browser monitoring and labelled **Demo timing** (3-second dwell). Visit your saved resource or pin the work tab from the extension popup. Switch to a configured domain. The companion shows a browser detour, Gemini writes a fresh line for this site and task, and Google TTS speaks it if unmuted. Allow a few seconds for generation. Choose **Bring me back** to restore the original tab and current work step.
5. **2:30 — User control.** Show **This is research**, **Taking a break**, mute, and the tray’s pause control. Explain that a configured site can still be useful research.

## Fast saved-work path

Settings → **Load sample assignment** → Return. This creates a labelled sample task with one completed step, sample notes, a saved overview link, and a paused session. Existing tasks are preserved; reloading does not overwrite edits to this demo task.

For a deterministic detour trigger without Chrome: resume/start a focus session, enable monitoring and **Demo timing**, then **Demo: simulate a browser detour**. The card says “DEMO · SIMULATED DETOUR”. The trigger timing is deterministic; wording is freshly generated by Gemini and speech uses real Google TTS when configured. Be explicit that the signal is simulated.

## Evidence from this build

- `npm test`: 30 domain/adapter tests, including persistence/recovery, disk failure, session transitions, provider and extension validation, nudge timing/suppression, generated nudge validation, no-speech failure handling, cancellation during text/audio generation, OAuth, and assignment discovery/sync.
- `npm run smoke`: actual Electron planning → work → checkpoint → restart → return → nudge research suppression → break/end.
- `npm run smoke:dev`: development renderer/CSP, non-focusable launcher, minimum width.
- `npm run test:extension`: real Chromium MV3 pairing, active-domain gating and exact-tab restoration with local fixture pages.
- `npm run test:loop`: Electron plus real Chromium → fresh Gemini YouTube text → switch to fresh Instagram text → work-tab restoration → notes → pause. Requires the local Google key. Audio muted, accelerated timing enabled.
- `npm run test:live`: real Gemini plan, fresh nudge writing and Google WAV generation.
- `npm run test:voice`: real Google audio emitted `playing` and `ended` in Electron, including a freshly generated playful Instagram line; manual demo signal, no fake audio. Text and speech both use Google; no canned line is supplied.
- `npm run smoke:google`: actual Electron sign-in callback, encrypted credentials, assignment/Drive discovery, PDF brief import, deadline update, restart refresh and disconnect. Google account responses are fixtures; see [Google setup](GOOGLE.md) for your own account.
- `npm run test:google-live`: real Gemini classification of synthetic assignment, study and social events.
- `npm run smoke:package`: packaged app, saved-work demo, restart, and absence of configured secrets in the bundle. Also verifies packaged PDF parsing when run after `smoke:google`.

Screenshots and live-check metadata are in ignored `test-results/`. The sample pages and data are isolated from your normal Chrome profile and workspace data. Native tray menus are created on actual launch; their visual appearance and all native menu clicks were not separately automated. Signing/notarization and limitations are in [SETUP.md](SETUP.md).
